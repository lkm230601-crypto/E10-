# 驗收檢查表 · E10

交件前自己逐條勾。**六項全過才算完成。**

- [ ] 能載入附的 data.csv（共 2012 筆），畫面正確顯示筆數，不會因為髒資料整頁壞掉
- [ ] 做到核心功能：看出重複發生的問題類型 → 列出未結案的問題 → 追到是哪個階段發現的
- [ ] 至少有一個 AI 功能會動：讓 AI 讀狀態與備註，自動判斷哪幾件真的還沒結案並排出優先序
- [ ] 這一頁在**手機上**打得開、看得清楚（現場的人多半站著用手機）
- [ ] 有一張架構圖，標出**哪一步是人在把關**
- [ ] 業主另外交代的那一條做到了（沒訪談過業主的話，你不會知道這條是什麼）
